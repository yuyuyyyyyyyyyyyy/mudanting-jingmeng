# 牡丹亭：书会记得你如何读过它

> 普通阅读器记得你读到哪里。这本书记得你怎样读到这里。
> 你划下的原文不会停留在这一页；后面的原文会回来回应它。
> AI 负责找，原文负责说——AI 全程沉默地工作，不替汤显祖写一个字，也不对读者做文学诊断。

当前唯一版本以第十出《惊梦》为深度体验，并开放第十二出《寻梦》的核心原文，使读者留下的句子真实跨出回来。

## 目标读者

高一学生。学过课本里的《皂罗袍》节选——「原来姹紫嫣红开遍，似这般都付与断井颓垣」——但没有读过完整的《惊梦》。

他们的困难是具体的：
- 知道名句，却无法把它放回杜丽娘的处境；
- 觉得曲牌文字是静态的，感受不到它的演出节奏；
- 容易把《惊梦》简化成爱情幻想，而忽略「春色—自伤—欲望—礼法」的层层变化。

这件作品要解决的核心问题：**让学生在完整走完《惊梦》后，真正理解「姹紫嫣红」这一句如何改变了杜丽娘的命运。**

## 核心主线

全书只有一条阅读主线，从开头持续到梦醒：

> **从哪一句开始，杜丽娘再也回不到原来的生活？**

- 一根 1px 胭脂**红线**从页顶垂到页底——主线问题的实体；未设开始时，线头处先放出完整问题
- 划下任何原文后有两个操作：**留下这句** / **设为开始**（已有开始则为**改从这里开始**）
- 「开始」落在句边成为一枚红色**针脚**；旧句不删除，针脚变淡留在原地——判断变化的过程在页面上随时可见
- 页边另有三处「低语」，只调整注意力，不索要答案
- 合页依次回放读者曾选过的开始，与已审核的原文关系并置，然后只问一句：「读完以后，你还把开始放在这里吗？」
- 确认后才出现「书替你找到了一处回应」，以及一枚未展开的《寻梦》书签：「这句话还没有结束。它将在第十二出《寻梦》中再次被听见。」（不剧透）
- 读者全程不划线也能走完：合页展示书自己发现的回声，并注明「下一次，你也可以留下一句自己的」

## 让普通读者读得下去

- **今译对照层**：每段原文配一层极淡的现代汉语（标注「今译 · 非原文」），默认关闭，右上角「今译」开关随时切换；原文仍是绝对主角，今译不参与划线
- **生成式声音层**（不是背景音乐）：隔 20–40 秒一声极轻的单音，像远处偶尔有人拨了一下弦；入梦后音域变低、间隔变长，梦醒即停。默认开启
- 生词带点，点开有释义；第一次遇到时有一次性轻提示
- 红线负责让人愿意开始，今译负责让人能够继续

## 一键启动

- Windows：双击 `start.bat`
- macOS / Linux：`./start.sh`
- 或手动：`npm install && npm run serve`（完整模式，含 AI 后端，<http://127.0.0.1:4173>）
- 开发模式：`npm run dev`（<http://127.0.0.1:5173>，注意：AI 接口在开发模式下不可用）
- DeepSeek：复制 `.env.example` 为 `.env.local`，在本机填入 `DEEPSEEK_API_KEY`；密钥不会进入浏览器。断网或接口失败时自动使用本地规则兜底。

## 两种阅读模式

- **演示节选**（默认）：按演示时长节选 16 个段落，页首明确标注「演示节选」，约 5–8 分钟完成闭环。
- **完整阅读**：开场左上角切换，加载第十出全部 20 个段落的完整原文。两种模式共用同一套代码与数据，节选对原文不做任何删改。

## 设计原则

- 没有积分、正确率、成就、关卡、结局分支和排行榜。
- 答案必须通过划原文表达，不提供选项；系统不立即判对错。
- 找不到可靠的原文关系时，书只记住划线，绝不编造联系。
- 任何动效、颜色、声音，只在它帮助读者继续读原文、或让两段原文产生新联系时才存在。

## 已知取舍

- 除第十出与第十二出当前开放内容外，其余各出仍标注「原文校对中 · AI关系整理中」，不由 AI 编造缺失章节。
- 词义释义目前覆盖第十出生词，正式产品可扩展为全词汇表。
