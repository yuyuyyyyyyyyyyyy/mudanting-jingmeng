# 《牡丹亭·惊梦》高中生体验测试包

这套材料用于验证一个具体问题：

> 学过《皂罗袍》、但没有完整读过《惊梦》的高中生，能否通过选择原文、重新判断和原文回应，从“会解释名句”走向“能依据上下文理解杜丽娘的变化”。

## 使用顺序

1. 先阅读 `01-主持人与访谈手册.md`，尤其是“不应该说的话”。
2. 每位体验者复制一份 `02-单场记录表.md`，用 S01、S02 等编号保存。
3. 体验中不要临时生成文学解释；如需人工模拟 Agent，只从 `03-原文回应候选表.md` 选择。
4. 招募后的筛选、家长知情和体验前提醒使用 `04-招募与知情沟通.md`。
5. 每完成一场，先独立整理观察，再讨论是否修改网页，避免被单个受访者带着反复改动。

## 本轮只验证四件事

- 目标学生的真实阅读困难是什么；
- “从哪一句开始”这个问题是否能促使他细读；
- 后文原文的回应是否能使他补充、修正或坚定解释；
- AI/Agent 的个性化选择是否比统一展示更有意义。

## 本轮不以这些作为成功标准

- 学生是否夸页面漂亮；
- 学生是否得出“女性觉醒”等预设结论；
- 学生是否把针脚移动到创作者认为最好的句子；
- 学生是否喜欢所有声音、动效和文案；
- 学生是否愿意为了礼貌说“很有意义”。

成功不是把学生带到同一个答案，而是让他能用比体验前更具体的原文证据说明自己的判断。
